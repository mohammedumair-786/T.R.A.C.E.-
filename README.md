# T.R.A.C.E.

**Trajectory Reconstruction & Automated Citywide Engine**

T.R.A.C.E. is an AI-powered, multi-camera Automatic Number Plate Recognition (ANPR) and urban traffic intelligence platform. It connects vehicle detections across cameras and time to reconstruct vehicle trajectories, visualize movement on GIS maps, generate city-wide traffic analytics, and provide real-time alerts.
